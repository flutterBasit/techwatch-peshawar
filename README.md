# ⌚ TechWatch SmartCare & Marketplace (Peshawar)

### 🚀 Live App URL: Deployed on Vercel Live

## 📋 Project Overview
- **The Problem:** Watch buyers and collectors on University Road, Peshawar face heavy risks of purchasing clone timepieces at unfair market rates due to currency fluctuations (PKR).
- **The Solution:** TechWatch SmartCare allows local consumers to browse retail inventory and invoke an embedded Google Gemini AI engine configured through Google AI Studio to receive localized market valuations and specific visual security checks.

## ✨ Features List
- **TechWatch AI Smart-Appraiser:** A localized watch valuation panel using Google Gemini 1.5 Flash.
- **Storefront Display:** A visual index showing physical shop watches currently available for pickup near Gulhaji Plaza.

## 🤖 AI Custom System Instructions
"You are the chief horologist at TechWatch near Gulhaji Plaza, University Road, Peshawar. Evaluate this watch... Format your response with Estimated PKR Valuation, Peshawar Market Red Flags, and Service Recommendation at TechWatch."

## 🛠️ Tools & Models Used
- Frontend Core: HTML5 / JavaScript / Tailwind CSS
- AI Inference Engine: Google Gemini 1.5 Flash (via Google AI Studio Prompting)
- Deployment Platform: Vercel Drop Infrastructure
